# Lumen Future Development

This directory records future Lumen capabilities and architectural requirements that have been identified but are **not currently committed roadmap items**.

These documents preserve engineering direction discovered during architecture, research, external-distribution and commercialisation discussions.

They should answer:

> **If Lumen needs to support this capability in the future, what architectural and engineering requirements have already been identified?**

They do not answer:

> **When will this be built?**

## Status

Content in this directory should be treated as:

- exploratory;
- architectural;
- subject to revision;
- unscheduled; and
- non-committed.

Moving a requirement into an active roadmap or component development plan should be an explicit decision.

## Commercial Deployment and Multi-User Architecture

`COMMERCIAL_DEPLOYMENT_AND_MULTI_USER.md`

Records requirements identified for a future shared and distributed Lumen deployment, including:

- distributed Lumen services;
- remote Servire operation;
- multiple users sharing Lumen infrastructure;
- authentication;
- authorisation and permissions;
- user isolation;
- session and evidence ownership;
- operational-log isolation;
- administrative control; and
- licence, deployment and user identity.

These requirements were identified while considering future Commercial Lumen deployment.

Their presence here does **not** establish final Commercial licensing terms or commit them to a particular release.
