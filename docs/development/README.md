# Lumen Development

This directory contains documentation concerned with the development and evolution of Lumen.

Development documentation describes capabilities, architectural changes, engineering requirements and implementation direction.

It is distinct from both:

- **licensing**, which defines permitted use and distribution conditions; and
- **roadmap commitments**, which identify work that has been accepted and scheduled or prioritised for implementation.

## Future Development

The `future/` directory contains architectural and development requirements that have been identified as potentially necessary for Lumen's future evolution but have **not yet become committed roadmap work**.

A document appearing under `future/` means:

> This capability or architectural requirement has been identified and is worth preserving, but its implementation scope, priority and schedule have not yet been decided.

Future-development documents may later:

- become roadmap items;
- be incorporated into component architecture;
- be divided into implementation milestones;
- change substantially as Lumen evolves; or
- be superseded by a different architectural approach.

Their purpose is to preserve useful engineering reasoning without prematurely turning it into a development commitment.
