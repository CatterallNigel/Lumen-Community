# Lumen Documentation

This directory is organised by **purpose first**, then by service where appropriate.

## Start here

- **architecture/** — core, ecosystem, installation and extension architecture.
- **services/** — documentation for each Lumen service, including its historical release/milestone notes.
- **research/** — model behaviour, capability, decision quality and research direction.
- **roadmaps/** — current development roadmap plus dated/historical plans.
- **engineering/** — Engineering Diary, historical narratives and digests.
- **standards/** — engineering, documentation, UI and operational standards.
- **vision/** — product and UI vision documents.
- **evidence/** — test logs, screenshots and other captured engineering evidence.
- **publications/** — outward-facing articles and long-form explanatory material.
- **brand/** — Lumen visual/brand guidance.
- **site/** — planning for the Lumen microsite.
- **archive/** — retained material that does not belong in the active navigation path.

## Documentation rule

The repository's existing documentation principle remains: significant topics should have one canonical engineering document, with other material treated as history, evidence, summary or superseded context.

No existing document content was changed during this reorganisation.
