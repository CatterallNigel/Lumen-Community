# M0.1 Work in Progress

This directory contains M0.1 documentation that remains under active review.

The documents here are relevant to the External Research Distribution and may describe intended behaviour, implementation direction, operating procedures or release conditions. However, they are **not yet part of the definitive reviewed M0.1 release definition**.

They should therefore be treated as **informational and subject to change** until their review is complete.

## Current Work-in-Progress Documents

The current work-in-progress set includes:

- **Research Licensing** — the licensing basis and conditions for the external research distribution;
- **Runtime Authorization and Code Protection** — the runtime authorization, installation identity, configuration protection and distribution-security design;
- **M0.1 User Manual** — the operating guide for researchers, including service-specific UI guidance and screenshots as the release UI stabilises.

## Promotion to the Release Root

When a document has completed review and its contents are considered definitive for M0.1, it should be moved from this directory into the parent M0.1 release directory.

The parent directory therefore represents the current reviewed release definition, while this directory represents documentation that is still being completed.

A document being present here does **not** mean that its subject is optional or excluded from M0.1. It means only that the document itself has not yet reached definitive reviewed status.

## Release Principle

> **Document status should be visible from repository structure, not inferred by the reader.**
