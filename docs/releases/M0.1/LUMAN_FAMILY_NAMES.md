# Lumen Family Names

## Document Revision History

| Version | Date | Author | Description |
| --- | --- | --- | --- |
| 1.0 | 2026-08-23 | Nigel Catterall | First reviewed release |

Lumen uses Latin component names deliberately. The Latin names provide a richer description of each service's role and give the service family a consistent identity, while the accompanying English responsibility provides an immediate, practical description for readers who do not know the Latin term.

For that reason, documentation should prefer the paired form **Latin name — English responsibility** when first introducing a service or where clarity matters. After the service has been established in context, the Latin component name may be used on its own.

The English responsibility is a descriptive aid rather than a replacement service name. This convention is particularly important in release and external research documentation, where readers should not have to infer that an English responsibility and a Latin component name refer to the same service.

| Component     | English responsibility | Servire tab                 |
| ------------- | ---------------------- | --------------------------- |
| **Servire**   | Service                | **Servire — Service**       |
| **Moderari**  | Orchestrator           | **Moderari — Orchestrator** |
| **Repetere**  | Replay                 | **Repetere — Replay**       |
| **Vestigare** | Trace                  | **Vestigare — Trace**       |
| **Pontis**    | Bridge                 | **Pontis — Bridge**         |
| **Nuntius**   | Messenger / Control Messaging | **Nuntius — Messenger** |
| **Rogare**    | Console                | **Rogare — Console**        |

| **Fiducia**   | Trust                  | **Fiducia — Trust**         |
