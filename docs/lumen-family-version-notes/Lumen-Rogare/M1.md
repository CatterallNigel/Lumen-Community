# Rogare M1 — Foundation

## Delivered

- Standalone `lumen_rogare` Python package.
- `python -m lumen_rogare` service entry point.
- Python 3.12 target.
- YAML configuration.
- Logs under `$ROOT/logs`.
- PID runtime marker under `$ROOT/run`.
- `/health` and `/status` endpoints.
- Tool-less `/api/console/message` endpoint.
- Pontis HTTP client boundary.
- `python -m lumen_rogare clear-logs` offline management command.
- Unit tests and static-quality configuration.

## Architectural boundary

Rogare owns only the conversational surface. It does not implement ACP, Pi, provider lifecycle, tool discovery, tool routing or tool execution. Pontis owns provider/session attachment.
