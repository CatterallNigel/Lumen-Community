# Lumen Rogare M3.1 — Start Session Control

## Objective

Provide a canonical Rogare session-start operation while preserving Rogare as a tool-less,
provider-independent conversational client.

## Contract

`POST /api/console/session/start`

Request:

```json
{
  "session_id": "rogare-test-1"
}
```

Rogare emits the existing OpenAI-compatible Pontis request containing the exact Lumen command:

```text
\obt rogare start
```

and includes `x-lumen-session-id`. If `pontis.working_directory` is configured it also includes
`x-lumen-cwd`.

Rogare does not open ACP, name Pi, discover tools or execute tools. Those remain Pontis/provider
responsibilities.
