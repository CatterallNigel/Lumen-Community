# Lumen Services

Each service folder contains its current architecture/overview/research material together where practical. Historical milestone and release material is kept in the service's `version-history/` directory.

Cross-service requirements that apply to multiple or all Lumen services may live at the root of this directory rather than being duplicated into individual service folders.

Current cross-service documentation includes:

- `LUMEN_SERVICES_PROTECTED_CONFIGURATION_AND_RUNTIME_DELIVERY.md` — common M0.1 requirements for protected configuration, authorised runtime configuration delivery, configuration classification, secret handling, and cross-service implementation boundaries.

Current service areas:

- `moderari/` — orchestration
- `pontis/` — client/session bridge
- `praebere/` — model/provider integration
- `vestigare/` — trace/evidence capture
- `repetere/` — replay/reproduction
- `aestimare/` — assessment
- `fiducia/` — Reasoning Assurance automation
- `rogare/` — operations/client console
- `servire/` — operational control plane
- `nuntius/` — control-command routing and response distribution
- `audire/` — distributed operational transport
