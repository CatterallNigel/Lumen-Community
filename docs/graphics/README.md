# Lumen Graphics

This directory contains visual assets for Lumen and the Lumen service family.

## Logos

Service and product logos are maintained under `logos/`, organised by Lumen component.

Where multiple formats or variants exist, they should be kept within the corresponding component directory.

Brand usage, identity and design guidance is maintained separately under:

`docs/brand/`

Graphics in this directory form part of the Lumen project assets and should not be assumed to carry separate redistribution or usage rights from the project merely because they are directly accessible from the repository.
