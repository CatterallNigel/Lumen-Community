# Lumen v3.2.14 — Operational Intelligence UI

v3.2.14 adds a live, read-only operational dashboard at `/operations` and a structured API at `/api/operations`.

The dashboard exposes current runtime status, active session and model, context utilisation, checkpoint count and persistence, dependency validation, distilled cognition, source coverage, recent tool activity, and the checkpoint/result timeline.

The existing `/checkpoints` interface remains available.
