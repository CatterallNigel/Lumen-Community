# Lumen Microsite Vision

**Status:** Vision Document  
**Version:** 1.0

---

# Purpose

The Lumen microsite is the public face of the Lumen++ ecosystem.

Its purpose is not to replace the engineering documentation, but to **distil it** into an accessible story that explains what Lumen++ is, why it exists and how its components work together.

---

# Vision

The microsite should allow a visitor to understand the Lumen++ ecosystem within a few minutes while providing clear paths into the detailed engineering documentation for deeper exploration.

It should communicate engineering rather than marketing.

---

# Guiding Principles

- Distil rather than duplicate.
- Link to canonical documentation.
- Explain the problem before the solution.
- Tell the evolution of the project.
- Remain technically accurate while being approachable.

---

# Target Audience

- Engineers
- Architects
- Researchers
- Technical decision makers
- Open-source contributors
- Anyone interested in trustworthy AI engineering

---

# Relationship to GitHub

GitHub remains the authoritative source for:

- Architecture
- Research
- Runtime guides
- Engineering diaries
- Version notes

The microsite provides the narrative and navigation into those documents.

---

# Success Criteria

A visitor should be able to:

- Understand the purpose of Lumen++ in under 10 minutes.
- Discover each major component.
- Navigate to detailed documentation in a single click.
- Leave with a clear understanding of how the ecosystem fits together.
